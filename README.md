## Featured projects
**[SGIDA](https://github.com/IgnacioSZ1904/Sistema-multiagente-basado-en-LM-para-la-prediccion-y-gestion-autonoma-de-retrasos-en-vuelos)**: LLM-based multi-agent system (LangGraph + Ollama) that analyzes flight delays, predicts their cascade impact with a Random Forest model and proposes autonomous mitigation actions. Final degree project, with FastAPI backend, DuckDB analytics and React dashboard.

**[AppTagaste](https://github.com/IgnacioSZ1904/AppTagaste)** · [Live demo](https://app-tagaste.vercel.app): full-stack web app to organize youth groups: shared calendar with iCal feed, group and attendance management, and a document library with Spanish full-text search. FastAPI + PostgreSQL + React/TypeScript, Google OAuth with role-based JWT, Google Drive Picker, CI with GitHub Actions and deployment on Render + Vercel. Documented with ADRs and OpenAPI.
